## 收录事件（2件全国性 + 1件台湾地区供参考）

### 事件一：江苏六县龙卷风特大灾害

| 项目 | 内容 |
|---|---|
| 发生地点 | 江苏省扬州、盐城、镇江等地（大丰、泰兴、邗江、姜堰、东台、丹徒6个市县的28个乡镇） |
| 发生时间 | 1996年7月15日凌晨 |
| 事件概述 | 6个市县28个乡镇先后遭受龙卷风袭击。倒塌房屋8200多间，因倒房砸死29人，受伤687人（其中重伤198人），农作物受灾面积达2万公顷，直接经济损失4.6亿元。是1990年代江苏最严重的龙卷风灾害之一。 |
| 日期核实 | 中国气象局《气象》1996年第10期《1996年7月天气概况》明确记载"15日凌晨，江苏省扬州、盐城、镇江等地6个市县的28个乡镇先后遭受龙卷风袭击"。 |

### 事件二：新疆沙雅"7·15"塔里木监狱暴狱事件

| 项目 | 内容 |
|---|---|
| 发生地点 | 新疆维吾尔自治区阿克苏地区沙雅县塔里木监狱 |
| 发生时间 | 1996年7月15日17时许（事件持续至7月16日围捕结束） |
| 事件概述 | 十余名重刑犯在外出劳动期间杀害看守武警人员，抢夺枪支、子弹和车辆后逃窜。阿克苏地区公安处组织平暴小分队围捕，7月16日凌晨与暴恐分子激烈交火，刑侦科侦察员郭双壮烈牺牲，年仅28岁。被称为"震惊全国的暴狱案"。 |
| 日期核实 | 新疆平安网（石榴云/新疆日报）英模事迹报道《郭双：血染大漠浩气存》明确记载"1996年7月15日17时许，沙雅县境内塔里木监狱发生震惊全国的暴狱案"。 |
| 性质说明 | 该事件为刑事案件/社会安全事件，非党政会议或政策发布类政治事件，故予以收录。 |

### 事件三（供参考）：伊能静专辑《自己》发行

| 项目 | 内容 |
|---|---|
| 发生地点 | 台湾地区（华纳唱片台湾发行） |
| 发生时间 | 1996年7月15日 |
| 事件概述 | 伊能静第16张个人国语专辑《自己》发行，共收录10首歌曲。是伊能静在飞碟唱片时期的最后一张原创录音室专辑，此后飞碟唱片被华纳音乐收购。 |
| 日期核实 | Apple Music、Shazam、酷狗音乐、QQ音乐等多个主流音乐平台均标注发行日期为1996年7月15日，各平台数据一致。 |
| 说明 | 该专辑由华纳唱片台湾发行，尚无证据表明1996年7月15日当天在中国大陆地区同步发行。如严格限定"中国大陆境内"，此条可不计入。 |
