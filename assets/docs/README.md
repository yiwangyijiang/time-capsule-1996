# 1996年7月15日 温州历史资料汇编

**目标日期**：1996年7月15日（周一，农历丙子年五月三十）
**目标地点**：中国浙江省温州市
**整理时间**：2026年9月6日
**整理原则**：准确性优先，所有结论附可核验来源；无法查证的内容标注"未查证"或"资料缺口"；搜索摘要和AI回答不作为最终证据。

## 文件夹结构

| 目录 | 内容 |
|---|---|
| 01_温州月相 | 当天月相名称、朔时刻、月面照明比例（计算值） |
| 02_温州天气 | 温州国家气象站实测气温、降水等数据 |
| 03_国内重大事件 | 当天中国境内非政治类重大事件 |
| 04_国际重大事件 | 当天全球（中国以外）非政治类重大事件 |
| 05_金曲榜前十名 | 各地区音乐榜单前十名及资料缺口 |
| 06_当日上映电影 | 当天全球主要电影市场上映影片及爱情片清单 |

## 资料完整性说明

- **月相**：完整，朔时刻来自NASA历表，照明比例为计算结果。
- **天气**：核心要素（气温、降水）完整，来自温州国家站实测；风向风速等未找到可靠记录。
- **国内事件**：收录2件经权威来源核实的全国性事件 + 1件台湾地区文化事件供参考。
- **国际事件**：收录5件经多源交叉验证的事件。
- **金曲榜**：仅Billboard Hot 100获得完整可核验前十名；英国OCC、日本Oricon及两岸三地华语榜单均为资料缺口（1996年周榜未数字化或官方档案禁止访问）。
- **上映电影**：八大主要市场当天均无院线首映（周一效应）；列出7月10-13日在映新片及6部可确认爱情片。
