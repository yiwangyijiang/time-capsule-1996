# 温州月相 — 资料说明

## 核心结论

**月相名称：残月（Waning Crescent）**

1996年7月15日（北京时间）为农历丙子年五月三十，是该朔望月的最后一天。朔（新月）发生于北京时间7月16日00:15，因此7月15日全天月亮均处于朔之前，月相为残月，月面照明比例极低（全天 <1.5%）。

## 数据性质说明

- 朔时刻：**天文历表计算结果**（NASA Reference Publication 1349），非实际观测记录。
- 照明比例：**基于朔时刻的简化模型计算结果**，非实际观测记录。
- 农历日期：历法计算，多家万年历交叉验证一致。

## 温州观测条件参考

温州经纬度约为北纬28.02°、东经120.67°。7月15日残月在日出前短暂可见于东方低空，因照明比例极低（<1.5%），肉眼观测极为困难。
